Questions

Designed around responsible practice.

Is identity verification live?

No. This prototype has no real OTP or government-ID verification. A production system needs secure verification providers, country-specific rules, consent, data minimization and retention controls.

Can clients hire an investigator now?

No real case can be submitted through this static demo. A backend, verified investigator onboarding, payment processing, case workflow and support process must be implemented.

Are the contracts legally binding?

The preview is illustrative only. A production e-sign flow should record explicit consent, document version, timestamps and a tamper-evident copy, and should be reviewed for each launch jurisdiction.

How is privacy handled?

This static page does not transmit form data to a server. A live service needs a privacy policy, secure storage, access controls, retention limits and a breach-response process.
